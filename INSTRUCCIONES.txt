AUDEX — USO DIRECTO DESDE LA PÁGINA WEB

NO NECESITAS:
- Descargar un ZIP.
- Instalar Python.
- Ejecutar Abrir_AudEX.bat.
- Configurar una API o una cuenta externa.

CÓMO TRANSCRIBIR:
1. Abre la página pública de AudEX.
2. Arrastra uno o varios audios a cualquier parte de la página, o pulsa “Seleccionar audios”.
3. Pulsa “Transcribir audios”.
4. La primera vez se descargará Whisper Base y los componentes necesarios. Espera a que termine la preparación.
5. AudEX procesa las grabaciones en tu navegador.
6. Edita, copia o descarga cada transcripción en TXT. Cuando haya marcas de tiempo, también puedes descargar SRT.

PRIVACIDAD:
El audio se procesa en el navegador de tu computadora y no se envía a un servidor de AudEX ni a una API de transcripción. La página descarga el modelo Whisper y la biblioteca de reconocimiento desde sus distribuidores. El navegador puede guardar el modelo en caché para los siguientes usos.

COMPATIBILIDAD:
Usa una versión reciente de Chrome o Edge. La lectura de algunos formatos depende de los códecs disponibles en el navegador.

VERSIÓN:
La versión activa se muestra al pie de la página. Comprueba que coincida con VERSION.txt en el repositorio. Cada modificación publicada incrementa el número de versión y queda anotada en CHANGELOG.md.
