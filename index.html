Ejecuta AudEX en tu computadora

La página pública solo muestra instrucciones. Para transcribir sin enviar tus grabaciones a servicios externos, inicia el servidor local de Python.

  1. Descarga el repositorio completo y descomprímelo.
  2. Instala Python 3.11 o 3.12 si aún no lo tienes.
  3. Haz doble clic en Abrir_AudEX.bat.
  4. La primera ejecución descargará Whisper Base; después podrás reutilizarlo.
