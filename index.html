Ejecuta AudEX en tu computadora

Esta dirección pública de GitHub Pages solo puede mostrar la interfaz. Para procesar archivos sin depender de los permisos CORS de Hugging Face, AudEX utiliza un pequeño servidor local de Python.

  1. Descarga el repositorio completo y descomprímelo en tu computadora.
  2. Instala Python 3.11 o 3.12 si aún no lo tienes.
  3. Haz doble clic en Abrir_AudEX.bat. El instalador preparará las dependencias y abrirá la aplicación.
  4. La primera ejecución descargará Whisper Base. Luego podrás reutilizar el modelo.
